# Home Screen — Designer A

## Layout

- Top bar: pet name (editable), points (top right)
- Center: pet animation based on satisfaction level
- Bottom: Feed / Walk / Spa buttons with cooldown timers
- Daily task progress box at bottom

## Pet animations (GIF)

| Satisfaction | Animation file |
|--------------|----------------|
| 100% | `pet_very_happy_dance_anim.gif` or `pet_very_happy_anim.gif` |
| 70–99% | `pet_happy_anim.gif` |
| 50–69% | `pet_normal_anim.gif` |
| 30–49% | `pet_boring_anim.gif` |
| 0–29% | `pet_unhappy_anim.gif` |
